# Quick Start Guide - Portfolio Website

## 🎯 Getting Started in 5 Minutes

### Step 1: View Your Portfolio
1. Open `index.html` in your web browser
2. You'll see a fully functional portfolio with placeholder content
3. Test the navigation, scroll animations, and responsive design

### Step 2: Customize Basic Information (5-10 minutes)

Edit `index.html` and replace:

1. **Name** - Find and replace "Micah Detamore" with your name (Ctrl+H)
2. **Email** - Find "micah@example.com" and replace with your email
3. **Phone** - Find "+1 (234) 567-8900" and replace with your phone
4. **Location** - Find "Your City, State" and replace
5. **Social Links** - Update these URLs:
   - LinkedIn: `https://linkedin.com/in/yourprofile`
   - GitHub: `https://github.com/yourprofile`
   - Twitter: `https://twitter.com/yourprofile`

### Step 3: Update About Section (2-3 minutes)

Find the About section and update:
- Your professional summary (1-2 paragraphs)
- Experience statistics (Years, Projects, Clients achieved)

### Step 4: Update Skills (3-5 minutes)

Edit the skills in each category to match YOUR actual skills:
- Frontend technologies
- Backend technologies
- DevOps & Tools
- Other specialties

### Step 5: Update Experience (5-10 minutes)

Replace timeline entries with your actual work experience:
- Job titles
- Company names
- Employment dates
- Key accomplishments

### Step 6: Update Projects (10-15 minutes)

Replace 6 featured projects with YOUR actual projects:
- Project name
- Project description
- Technologies used
- Link to project (GitHub, demo, etc.)

### Step 7: Create Your Own (Optional - 5 minutes)

Personalize the design:
- Change colors in `css/style.css` (see COLOR VARIABLES section)
- Update hero subtitle to your professional tagline
- Modify any text to reflect your personality and style

## 📱 Test Responsiveness

1. **Desktop**: View at full screen
2. **Tablet**: Resize browser to 768px width
3. **Mobile**: Resize browser to 480px width
4. Use Chrome DevTools (F12) → Device Toolbar for testing different devices

## 🆘 Common Issues & Solutions

### Portfolio not showing?
- Make sure `index.html` is in the Portfolio folder
- Check file paths are correct
- Try a different browser

### Mobile menu not working?
- Check JavaScript is enabled
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser

### Styles look wrong?
- Refresh page (Ctrl+F5)
- Check if CSS files are in `css/` folder
- Verify file paths in index.html

### Submit button not working?
- It's designed to log to console (open DevTools - F12)
- To make emails work, configure Formspree or EmailJS
